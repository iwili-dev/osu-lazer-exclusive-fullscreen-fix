# osu!lazer Fix - настоящий эксклюзивный полный экран (убирает инпут-лаг)

Неофициальный фикс для **osu!lazer 2026.1005.0** на Windows. Добавляет настоящий эксклюзивный
полный экран (рендерер Direct3D 11), который убирает инпут-лаг. Автор: **iwili**.

[English version](README.md)

> **Прочитай сначала.** Это НЕ официальная версия игры. Фикс изначально создавался для личного
> использования. Если что-то пойдёт не так, автор не виноват. Я не знаю, банят ли аккаунт за
> использование изменённых файлов игры: может быть да, а может и нет. Всё делается на ваш страх и риск.

## Две редакции

| | **Online** | **Partial offline (частичный оффлайн)** |
|---|---|---|
| Подменяемые файлы игры | `ppy.Veldrid.dll` | `ppy.Veldrid.dll`, `osu.Framework.dll` |
| Эксклюзивный полный экран | да | да |
| Лимит FPS | обычный лимит игры (1000) | **2000** |
| Онлайн-функции | не блокируются | только: вход в аккаунт, скачивание карт внутри игры, топ на карте, список игроков онлайн. Нет мультиплеера, игры на ранг и отправки результатов |

## Установка

1. Распакуй весь архив, закрой osu!lazer.
2. Запусти `apply.bat`, прочитай предупреждение, нажми `Y`.
3. Если игра стоит не в стандартной папке (например, на диске D:), откроется окно: выбери папку osu!lazer.
4. В игре: Settings - Graphics - Renderer: **Direct3D 11**, Layout mode: **Fullscreen**.

Чтобы убрать фикс, запусти `revert.bat`. Полные инструкции (на русском и английском) лежат внутри каждого архива
(`README_RU.txt`, `README_EN.txt`) и в папках `osu-fix-*` этого репозитория.

Если osu!lazer обновится сама, фикс пропадёт, и понадобится новая версия фикса.

### Графический планшет

Если курсор лагает при игре на графическом планшете, скорее всего, причина в отдельной программе OpenTabletDriver. Лучше используй встроенный драйвер планшета в osu!lazer (Settings - Input - Tablet).

### Несколько мониторов

Если у тебя 2 и больше мониторов, лучше не пользоваться Alt+Tab, пока игра в эксклюзивном полном экране.
